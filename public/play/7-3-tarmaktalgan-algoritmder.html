🔀 Тармақталған алгоритмдер

Python: if, elif, else · 7.3.2.1

Сабақтың мақсаты

Тармақталған алгоритм деген не екенін, шарт жазу ережесін біліп, if, elif, else қолданатын бағдарлама құру.

Жетістік критерийлері

  • Тармақталған алгоритмді түсіндіреді
  • Шартты салыстыру операторларымен жазады
  • if, if-else, if-elif-else бағдарламасын құрады
  • Кодтағы қатені тауып, түзетеді

🤔 Проблемалық сұрақ

Бағдарлама шартқа қарай әр түрлі әрекет жасай алады ма? Мысалы, жаңбыр жауса – қолшатыр аламыз, жаумаса – алмаймыз.

Алгоритм түрлері

Сызықтық
әрекеттер бірінен кейін бірі орындалады
Тармақталған
шартқа қарай жол таңдалады
Циклдік
әрекет қайталанады

Тармақталған алгоритм – шарттың рас немесе жалған болуына қарай әр түрлі әрекет орындалатын алгоритм.

❓ Толық емес тармақталу: if

age = int(input("Жасың: "))
if age >= 18:
    print("Кіре аласың")
print("Бағдарлама аяқталды")
  • Шарттан кейін қос нүкте : қойылады
  • Шартқа тәуелді жол шегіністен (4 бос орын) жазылады
  • Шарт рас болса ғана шегіністі жол орындалады

⚖️ Салыстыру операторлары

ОператорМағынасыМысал
==теңx == 5
!=тең емесx != 5
> / <үлкен / кішіx > 5
>= / <=үлкен немесе тең / кіші немесе теңx >= 5

⚠️ = – мән меншіктеу, == – салыстыру. Шарттың нәтижесі: True немесе False.

↔️ Толық тармақталу: if – else

t = int(input("Температура: "))
if t >= 20:
    print("Жылы")
else:
    print("Салқын")

Шарт рас болса – if блогы, жалған болса – else блогы орындалады. Екеуі бірге орындалмайды.

🔀 Көп тармақты таңдау: elif

mark = int(input("Баға: "))
if mark == 5:
    print("Өте жақсы")
elif mark == 4:
    print("Жақсы")
elif mark == 3:
    print("Қанағат")
else:
    print("Қайта қара")

Шарттар жоғарыдан төмен тексеріледі. Бірінші рас шарттың блогы орындалып, қалғандары тексерілмейді.

🔗 Күрделі шарт: and, or

ОператорРас болады, егер…
andекі шарт та рас болса
orкемінде бір шарт рас болса
if x > 0 and x < 10:
    print("1-ден 9-ға дейін")

Есте сақта

  • if, elif, else жолдарының соңында : болады
  • Блок шегіністен жазылады
  • Салыстыру үшін == қолданамыз
  • input() мәтін қайтарады, санға int() арқылы айналдырамыз
