3. Кодты толықтыр — 2 балл

print( _____ (a) )   # элементтер саны

4. Код нәтижесін болжа — 2 балл

a = [5, 2, 8, 4]
s = 0
for x in a:
    if x % 2 == 0:
        s += x
print(s)
